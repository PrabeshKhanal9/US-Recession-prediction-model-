# US-Recession-prediction-model-
An attempt to predict US Recession using different economical variables. 

## Variables Used
- T10Y3M (Yield Curve, lagged 9 & 12 months)
- Unemployment Rate (3m & 6m change)
- CPI & Year-over-Year Inflation
- S&P 500
- WTI Oil Price
- Median House Price

## Model Performance
- AUC Score: 0.984
- Accuracy: 91.5%
- Recession Recall: 82%
- Only 3 false positives across 750+ months of data

## Key Finding
The model successfully identifies all major US recessions from 1963–2026
with only 3 false positives, all of which are economically explainable.
